# الجدول الدوري التفاعلي ثلاثي الأبعاد

جدول دوري للعناصر تفاعلي، عالي الأداء، وثلاثي الأبعاد يتميز بأربعة تخطيطات ديناميكية: **الجدول (Table)**، **الكرة (Sphere)**، **الحلزون (Helix)**، و **الشبكة (Grid)**. تم بناء هذا المشروع باستخدام HTML و CSS نقيين (Vanilla)، ومكتبة GSAP، وتحويلات CSS ثلاثية الأبعاد (3D Transforms)، وهو يتكيف تلقائيًا ليناسب أي حجم شاشة، مما يجعله مثاليًا لشاشات سطح المكتب أو العرض الطولي على الهواتف المحمولة (مثل فيديوهات تيك توك).

## 1. ملف HTML (`index.html`)

يعتبر ملف HTML الأساس الهيكلي للمشروع. يقوم بإعداد واجهة العرض (Viewport)، وربط الملفات والمكتبات الخارجية، ويحتوي على أزرار التحكم، ويؤسس قالبًا (Template) لعناصر الجدول الدوري.

```html
<!DOCTYPE html>

```

* **شرح السطر:** يعرّف أن هذا المستند مكتوب بصيغة HTML5، ويخبر متصفح الويب بكيفية قراءة وعرض الصفحة بشكل صحيح.

```html
<html lang="en">

```

* **شرح السطر:** الوسم الجذري الذي يحتوي على كل محتوى الصفحة. خاصية `lang="en"` تحدد أن اللغة الأساسية للصفحة هي الإنجليزية.

```html
<head>
  <meta charset="UTF-8">

```

* **شرح السطر:** يفتح قسم `<head>` الذي يحتوي على البيانات الوصفية (Metadata) غير المرئية. `<meta charset="UTF-8">` تضمن فك تشفير الرموز الخاصة والحروف البرمجية بشكل صحيح بدون أخطاء.

```html
  <meta name="viewport" content="width=device-width, initial-scale=1.0">

```

* **شرح السطر:** ضروري لتجاوب الشاشة مع الهواتف. يُجبر عرض صفحة الويب على التوافق مع العرض الفعلي لشاشة الجهاز، ويضبط مستوى التكبير المبدئي على 100%.

```html
  <title>Periodic Table - Auto Fit Layout</title>

```

* **شرح السطر:** يحدد النص الذي يظهر على علامة تبويب متصفح الويب (اسم الصفحة).

```html
  <link rel="stylesheet" href="style.css">

```

* **شرح السطر:** يربط ملف التنسيقات الخارجي (`style.css`) لتطبيق الألوان والتصميمات والهيكل على العناصر.

```html
  <script src="https://cdn.jsdelivr.net/npm/gsap@3.12.5/dist/gsap.min.js"></script>
</head>

```

* **شرح السطر:** يستدعي مكتبة **GSAP** للرسوم المتحركة من شبكة خوادم سريعة (CDN). تتولى هذه المكتبة جميع الحسابات الرياضية والحركة السلسة في الفراغ ثلاثي الأبعاد. أخيرًا، `</head>` يغلق قسم البيانات الوصفية.

```html
<body>

```

* **شرح السطر:** يفتح هيكل الصفحة المرئي حيث يتم وضع جميع العناصر التي تظهر للمستخدم.

```html
  <div class="controls">
    <div class="controls-group">

```

* **شرح السطر:** ينشئ حاوية عامة (`controls`) وداخلها غلاف تجميعي (`controls-group`) لاحتواء ومحاذاة أزرار القائمة.

```html
      <button class="button is-active toggle" id="table">Table</button>
      <button class="button toggle" id="sphere">Sphere</button>
      <button class="button toggle" id="helix">Helix</button>
      <button class="button toggle" id="grid">Grid</button>
    </div>
  </div>

```

* **شرح السطر:** ينشئ أربعة أزرار تفاعلية. كل زر يأخذ كلاس `button` (للتصميم) و `toggle` (للتعرف عليه في الجافاسكريبت). زر `table` يحتوي على كلاس `is-active` لأنه يكون مفعلًا كوضع افتراضي في البداية. كل زر له `id` فريد يعبر عن شكل التخطيط الخاص به.

```html
  <div class="watermark">
    <div class="brand-name">modi</div>
    <div class="tiktok">TikTok: @MJcoders</div>
    <div class="github">GitHub: EngModiDev</div>
    <div class="copy">© modi@mhmwd_</div>
  </div>

```

* **شرح السطر:** يحتوي على العلامة المائية التي تظهر على الشاشة لإثبات ملكية التصميم وحقوق النشر. تتضمن اسم المبتكر، وحساب التيك توك، والجيت هاب، وعلامة حقوق الطبع والنشر.

```html
  <div id="scene">
    <div id="scene-content"></div>
  </div>

```

* **شرح السطر:**
* `#scene` هو الحاوية الخارجية التي تعمل كصندوق العرض ثلاثي الأبعاد (توفر منظور العمق).
* `#scene-content` هي الحاوية الداخلية للإحداثيات. يتم وضع جميع كروت العناصر الكيميائية داخلها. تدوير هذا العنصر الوحيد يؤدي إلى تدوير الكون ثلاثي الأبعاد بالكامل.



```html
  <template id="element-template">
    <div class="element">
      <div class="element-number"></div>
      <div class="element-symbol"></div>
      <div class="element-title"></div>
    </div>
  </template>

```

* **شرح السطر:** وسم `<template>` يحتفظ بكود HTML لا يتم عرضه عند تحميل الصفحة. بدلاً من ذلك، تقوم الجافاسكريبت بنسخ هذا القالب 118 مرة لتوليد كروت فعلية تحتوي على أماكن للرقم الذري، الرمز الكيميائي، والاسم الكامل للعنصر.

```html
  <script src="script.js"></script>
</body>
</html>

```

* **شرح السطر:** يربط ملف الجافاسكريبت (`script.js`) لتشغيل المنطق البرمجي، وذلك قبل إغلاق جسم الصفحة (body) مباشرة.

## 2. ملف التنسيقات (`style.css`)

هذا الملف مسؤول عن تجميل عناصر الواجهة وإنشاء البيئة ثلاثية الأبعاد باستخدام قواعد التصميم المدعومة بتسريع كارت الشاشة (GPU).

```css
:root {
  --bg: #060812;
  --panel: #0f1724;
  --accent: #66d0ff;
  --muted: #9fb7d8;
}

```

* **شرح السطر:** يعرّف متغيرات CSS عامة (Tokens). هذا يسهل إعادة استخدام الألوان في الكود كله. `--bg` هو الأزرق الداكن/الأسود للأساسية، `--panel` هو خلفية الكروت، `--accent` هو لون سماوي ساطع (Cyan)، و `--muted` هو لون رمادي مزرق فاتح للنصوص الفرعية.

```css
body {
  margin: 0;
  background-color: var(--bg);
  color: #e6eef8;
  font-family: 'Inter', Roboto, Arial, sans-serif;
  overflow: hidden;
  height: 100vh;
}

```

* **شرح السطر:** يزيل الهوامش الافتراضية للمتصفح، يطبق الخلفية الداكنة، يحدد لون النص الافتراضي، ويختار خطوط عصرية. كما يعطل شريط التمرير (`overflow: hidden`)، ويقفل ارتفاع الصفحة ليطابق ارتفاع الشاشة بالظبط (`100vh`).

```css
.controls {
  position: absolute;
  top: 25px;
  z-index: 100;
  left: 50%;
  transform: translateX(-50%);
}

```

* **شرح السطر:** يضع أزرار التحكم في مكان ثابت أعلى الصفحة (25 بكسل من الأعلى). يعطيها أولوية الظهور فوق باقي العناصر (`z-index: 100`)، ويقوم بتوسيطها أفقيًا باستخدام `left: 50%` مع سحبها للخلف بمقدار نصف عرضها (`translateX(-50%)`).

```css
.button {
  background: var(--panel);
  border: 1px solid rgba(38, 53, 74, 0.9);
  color: var(--accent);
  padding: 10px 18px;
  margin: 0 6px;
  border-radius: 8px;
  cursor: pointer;
  font-weight: 700;
  transition: background-color 0.2s, color 0.2s, transform 0.15s;
  text-transform: capitalize;
}

```

* **شرح السطر:** ينسق الأزرار بحواف دائرية، مساحات داخلية (Padding)، وخطوط عريضة (`font-weight: 700`)، مع تحويل المؤشر لعلامة اليد عند المرور عليها. خاصية `transition` تجعل أي تغيير في اللون أو الحجم يحدث بشكل سلس.

```css
.button.is-active, .button:hover {
  background: var(--accent);
  color: var(--bg);
  box-shadow: 0 0 15px rgba(102,208,255,0.35);
}

```

* **شرح السطر:** عندما يكون الزر مفعلًا (`.is-active`) أو يمر الماوس فوقه (`hover`)، تتحول خلفيته للون السماوي، ويتغير لون النص للأزرق الداكن، ويظهر له توهج مضيء (ظل نيون).

```css
.button:active {
  transform: scale(0.95);
}

```

* **شرح السطر:** يصغر حجم الزر قليلًا (ليصبح 95% من حجمه الطبيعي) عند الضغط عليه الفعلي ليعطي إحساسًا واقعيًا بالضغط.

```css
.watermark {
  position: absolute;
  bottom: 25px;
  right: 25px;
  text-align: right;
  z-index: 100;
  pointer-events: none;
  background: rgba(15, 23, 36, 0.6);
  padding: 15px 20px;
  border-radius: 12px;
  border: 1px solid rgba(38, 53, 74, 0.5);
  backdrop-filter: blur(4px);
  box-shadow: 0 10px 30px rgba(0,0,0,0.5);
}

```

* **شرح السطر:** يضع العلامة المائية في الزاوية السفلية اليمنى. يستخدم تأثير الزجاج الشفاف المُغَبّش (`backdrop-filter: blur`). خاصية `pointer-events: none` تجعل هذه العلامة غير قابلة للنقر، بحيث لا تعيق المستخدمين من سحب وتدوير المشهد ثلاثي الأبعاد من خلالها.

```css
.brand-name {
  font-size: 24px;
  font-weight: 900;
  color: var(--accent);
  margin-bottom: 5px;
  text-shadow: 0 0 10px rgba(102,208,255,0.4);
}

```

* **شرح السطر:** يحدد حجم وتنسيق اسم المبتكر (`modi`) بخط سميك جدًا وتأثير ظل مضيء مخصص.

```css
.tiktok, .github { ... }
.copy { ... }

```

* **شرح السطر:** مجموعة تنسيقات لضبط أحجام وسمك الخطوط الخاصة بحساب التيك توك، وجيت هاب، وسطر حقوق النشر ليظهروا بشكل متناسق.

```css
#scene {
  width: 100vw;
  height: 100vh;
  perspective: 3000px;
  overflow: hidden;
  touch-action: none;
}

```

* **شرح السطر:** الحاوية الرئيسية للعرض. `perspective: 3000px` هي الخاصية الأهم لتفعيل الـ 3D: فهي تعمل كعدسة كاميرا افتراضية، حيث تظهر الأشياء البعيدة أصغر حجمًا. `touch-action: none` تمنع حركات الموبايل الافتراضية (مثل التمرير أو التحديث) من التدخل أثناء تدوير وسحب المشهد.

```css
#scene-content {
  position: absolute;
  left: 50%;
  top: 50%;
  transform-style: preserve-3d;
  will-change: transform;
}

```

* **شرح السطر:** يتمركز تمامًا في منتصف الشاشة. `transform-style: preserve-3d` تخبر المتصفح أن العناصر الموجودة بالداخل يجب أن تحافظ على أبعادها الثلاثية بدلًا من أن تظهر مسطحة. `will-change: transform` ترسل هذا العنصر للمعالجة المسبقة في كارت الشاشة (GPU) لضمان أقصى سرعة.

```css
.element {
  position: absolute;
  left: -60px;
  top: -70px;
  ...
}

```

* **شرح السطر:** يوحد تصميم الكروت الكيميائية. بتحديد `left: -60px` و `top: -70px` (وهما بالضبط نصف عرض وطول الكارت)، نضمن أن المركز الهندسي الدقيق لكل كارت متطابق مع نقطة ارتكازه الافتراضية. يستخدم الـ Flexbox لتركيز المحتوى في المنتصف ويمنع تظليل النصوص بالغلط.

```css
.element:hover {
  border-color: var(--accent);
  box-shadow: 0 0 25px rgba(102,208,255,0.4);
}

```

* **شرح السطر:** يضيف تأثير إضاءة وتوهج للحدود الخارجية للكارت عندما يمر الماوس فوقه.

```css
@media (max-width: 700px) { ... }

```

* **شرح السطر:** شرط الاستجابة (Responsive). إذا كانت الشاشة ضيقة (مثل الموبايل أو العرض الطولي)، يتم تصغير حجم العلامة المائية تلقائيًا حتى لا تغطي على المشهد ثلاثي الأبعاد.

## 3. ملف الجافاسكريبت (`script.js`)

هذا الملف هو العقل المدبر للمشروع. يدير قاعدة البيانات، ينشئ الكروت، يحسب الإحداثيات الرياضية المعقدة للأشكال المختلفة، ينسق الحركة مع GSAP، ويتولى التكبير التلقائي ودوران المشهد.

```javascript
const sceneContent = document.getElementById('scene-content');
const template = document.getElementById('element-template');

```

* **شرح السطر:** يقوم بالبحث في الـ DOM لربط حاوية الـ 3D الأساسية (`#scene-content`) وقالب الكارت (`#element-template`) بمتغيرات داخل الكود.

```javascript
const rawData = "1,H,Hydrogen;2,He,Helium;3,Li,Lithium;...;118,Og,Oganesson";

```

* **شرح السطر:** سلسلة نصية مضغوطة تحتوي على بيانات الـ 118 عنصرًا كيميائيًا، مفصولة بفاصلة منقوطة للحفاظ على حجم الكود صغيرًا وخفيفًا.

```javascript
const elements = rawData.split(';').map(item => { ... });

```

* **شرح السطر:** يقوم بتحليل (Parse) هذه السلسلة النصية المعقدة:
1. `.split(';')` يقسم النص الطويل إلى 118 قسم.
2. `.map(...)` يمر على كل قسم.
3. `item.split(',')` يفصل البيانات بداخل كل قسم بناءً على الفاصلة العادية ليخرج (الرقم، الرمز، الاسم).

* `cardElements` هي قائمة فارغة ستُخزن روابط (References) للكروت الفعلية الموجودة على الشاشة.
* `layouts` هو كائن (Object) سيحفظ الإحداثيات الثلاثية ($X, Y, Z$ والدوران) لكل شكل من التخطيطات الأربعة.



```javascript
elements.forEach((data) => {
  const clone = template.content.cloneNode(true);
  const card = clone.querySelector('.element');

```

* **شرح السطر:** يبدأ حلقة تكرارية (Loop) لتوليد العناصر. `cloneNode(true)` تأخذ نسخة طبق الأصل من كود HTML الموجود في الـ Template، ونستخرج منها الكارت.

```javascript
  card.querySelector('.element-number').textContent = data.number;
  ...

```

* **شرح السطر:** يملأ البيانات (الرقم الذري، الرمز، والاسم) داخل الأماكن المخصصة لها في الكارت المنسوخ.

```javascript
  gsap.set(card, {
    x: (Math.random() - 0.5) * 4000,
    y: (Math.random() - 0.5) * 4000,
    z: (Math.random() - 0.5) * 4000,
    ...
  });

```

* **شرح السطر:** يحدد مكانًا عشوائيًا لكل كارت في الفراغ بمجرد تحميل الصفحة. هذا يجعل الكروت مبعثرة في مساحة ضخمة (بين -2000 و 2000)، لتطير الكروت من هذه الأماكن العشوائية وتتجمع عند بدء التشغيل.

```javascript
  sceneContent.appendChild(card);
  cardElements.push(card);

```

* **شرح السطر:** يضيف الكارت فعليًا إلى الشاشة داخل الحاوية المرئية، ثم يحفظه في قائمة `cardElements` للتحكم فيه لاحقًا.

```javascript
  card.addEventListener('pointerenter', () => { ... });
  card.addEventListener('pointerleave', () => { ... });

```

* **شرح السطر:** يربط أحداث الماوس. عند الوقوف على كارت، تقوم مكتبة GSAP بتكبيره بنسبة 15% وتغيير لونه باستخدام حركة زنبركية مريحة للعين (`ease: "back.out(2)"`). وعند إبعاد الماوس يعود لحجمه الطبيعي.

```javascript
(function generateLayouts() {
  const cols = 18, gapX = 140, gapY = 160; ...

```

* **شرح السطر:** دالة يتم تنفيذها فورًا (IIFE) وظيفتها حساب إحداثيات كل الأشكال الهندسية. تُعرف في البداية المعطيات الرياضية مثل: 18 عمود للجدول الدوري، وأنصاف أقطار الكرة والحلزون، ومسافات الشبكة.

```javascript
  cardElements.forEach((_, i) => {

```

* **شرح السطر:** يمر على كل كارت لحساب موقعه الرياضي الفريد بناءً على رقمه (Index `i`).

```javascript
    // Table
    layouts.table.push({
      x: (i % cols - cols / 2 + 0.5) * gapX, ...
    });

```

* **شرح السطر:** يحسب إحداثيات الجدول المسطح.
* عملية باقي القسمة `i % cols` تحدد رقم العمود (من 0 لـ 17).
* القسمة المباشرة `i / cols` تحدد رقم الصف.
* يتم طرح قيم معينة لضمان تمركز الجدول بالكامل حول النقطة المركزية `(0,0,0)`.



```javascript
    // Sphere
    const phi = Math.acos(-1 + (2 * i) / l); ...

```

* **شرح السطر:** يوزع الـ 118 عنصر بانتظام لتكوين كرة ثلاثية الأبعاد باستخدام خوارزمية (Spherical Fibonacci Grid). يحسب زوايا الطول والعرض، ويحولها لإحداثيات ديكارتية ($X, Y, Z$). كما يقوم بحساب الدوران الجانبي (`rY`) ليجعل كل كارت ينظر للخارج بعيدًا عن مركز الكرة.

```javascript
    // Helix
```

# 📐 الشرح الرياضي للتخطيطات

### 1. تخطيط الكرة (Spherical Fibonacci Grid)

لترتيب العناصر في كرة دون تكدسها عند الأقطاب العلوية والسفلية، نستخدم توزيع حلزون فيبوناتشي:


$$\phi_i = \arccos\left(-1 + \frac{2 \cdot i}{N}\right)$$

$$\theta_i = \sqrt{N \cdot \pi} \cdot \phi_i$$

حيث:

* $i$ هو رقم تسلسل العنصر (Index).
* $N$ هو العدد الإجمالي للعناصر (118).
* $\phi_i$ تمثل زاوية خطوط العرض من 0 إلى $\pi$.
* $\theta_i$ تمثل زاوية خطوط الطول (السمت).

ثم نحول هذه الزوايا الكروية إلى إحداثيات ديكارتية ($X, Y, Z$) ليعرف المتصفح أين يضعها في الفراغ:


$$X = R \cdot \cos(\theta) \cdot \sin(\phi)$$

$$Y = R \cdot \sin(\theta) \cdot \sin(\phi)$$

$$Z = R \cdot \cos(\phi)$$

### 2. الحلزون (الأسطوانة اللولبية)

بالنسبة للشكل الحلزوني، توضع العناصر على مسار لولبي يحيط بأسطوانة وهمية، حيث تزيد الزاوية مع كل عنصر ويتغير الارتفاع بشكل خطي:


$$\theta_i = i \cdot 0.25 + \pi$$

$$X_i = R_{helix} \cdot \cos(\theta_i)$$

$$Y_i = -(i \cdot \text{separation}) + \text{offset}$$

$$Z_i = R_{helix} \cdot \sin(\theta_i)$$

يخلق هذا التوزيع تأثيرًا كدرج السلم الحلزوني الذي يلتف حول المحور المركزي.
